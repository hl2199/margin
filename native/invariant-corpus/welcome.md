# Welcome to Margin

Click anywhere to edit. Formatting stays rendered; only the part under your cursor shows its Markdown. There are no modes to switch.

Open a document with **⌘O**, save with **⌘S**, and undo with **⌘Z**. Find text with **⌘F**. Start a new document with **⌘N**.

## Write naturally

Add **bold**, *italic*, a [link](https://commonmark.org), or a little `code`. Your writing stays in a plain Markdown file.

> A familiar reading experience, with room to edit.

- [x] Read and write in the same place
- [ ] Start your next note

## Tables, math, and diagrams

| Shortcut | Action |
| --- | --- |
| ⌘O | Open a file |
| ⌘S | Save changes |
| ⇧⌘S | Save a copy |

Math works inline, like $a^2 + b^2 = c^2$, or on its own:

$$
E = mc^2
$$
